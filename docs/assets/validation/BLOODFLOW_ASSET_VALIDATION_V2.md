## Package and material audit

- Every stage declares `metersPerUnit = 1` and `upAxis = "Y"`.
- Exports omit cameras, lights, and world materials.
- The complete cutaway package contains its root USDC plus these three packed maps:
  - `textures/arterial_wall_albedo_v1.png`
  - `textures/arterial_wall_normal_gl_v1.png`
  - `textures/arterial_wall_roughness_v1.png`
- USD inspection confirms the media material references the packaged albedo, OpenGL normal, and roughness maps.
- The normal and roughness images are treated as non-color data in Blender.
- Individual packages are intended for lazy loading. The 7.6 MB combined package is a QA/presentation convenience, not the default runtime payload.

## Reproduction

```bash
/Applications/Blender.app/Contents/MacOS/Blender \
  --background \
  --python vision_pro_stroke_kit_v2/source/build_cerebral_bloodflow_v2.py

/usr/bin/usdchecker --arkit \
  vision_pro_stroke_kit_v2/exports/usdz/cerebral_bloodflow_animation_v2.usdz

xcrun --sdk macosx swiftc -O \
  -framework Foundation -framework RealityKit \
  vision_pro_stroke_kit_v2/research/realitykit_animation_probe.swift \
  -o /tmp/realitykit_animation_probe
```

This is technical and visual validation only. It does not validate clinical accuracy, physiological timing, patient comprehension, or quantitative hemodynamics. The module remains `REQUIRES_SPECIALIST_REVIEW` and is not for clinical decisions.
