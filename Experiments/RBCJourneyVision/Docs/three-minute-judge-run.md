# Three-minute judge run

This is the shortest honest demonstration of the app's strongest idea: a
blockage and the tissue beyond it are one spatial relationship.

## 0:00–0:30 — Cross the threshold

Start with **Entering the brain**. Advance through the four calm readings while
the cortical shell grows from an object ahead into the room around the wearer.

Say: “A video can show anatomy. Spatial computing can preserve the relationship
between a route, an interruption, and what lies beyond it.”

## 0:30–1:25 — Follow one route

Choose **Enter the brain**, then show the overview. Follow the continuous lumen
from the Circle context toward the named example interruption. Pause the actual
RealityKit flow animation at the obstruction.

Say: “The app does not predict a patient outcome. It makes a generic causal
relationship inspectable without moving the learner.”

## 1:25–2:10 — Reveal the consequence

Advance to the downstream tissue field. Pull back far enough that the route,
blockage, and affected territory can be understood together. Reveal the
bounded fact only if the judge asks for more detail.

## 2:10–2:40 — Hand the learner agency

Show the **Region Portal Reel**. Keep exactly three destinations visible, then
choose one of the six locally authored regions. Demonstrate that the surrounding
cortical context persists and only one region transfer is active.

## 2:40–3:00 — Close with evidence

- **Interface:** one sentence, one action, reversible choices, no dashboard in
  the immersive scene.
- **Technical:** native Swift 6, SwiftUI, RealityKit, geometry-derived anchors,
  animated USDZ content, real pause/resume, deterministic proof routes, 42
  contract checks.
- **Story:** threshold → route → interruption → territory → self-directed region.
- **Problem fit:** spatial simultaneity explains what a serial 2D frame asks the
  learner to reconstruct mentally.
- **Novelty:** the brain changes from object to environment; portals are places,
  not pop-up windows.
- **Delight:** the user enters deliberately, then chooses where the exhibit goes.

## Claims boundary

Simulator proof establishes composition and deterministic state access. It does
not establish XCAT comfort, hand-target quality, spatial-audio perception,
teaching efficacy, specialist validation, or clinical accuracy.
