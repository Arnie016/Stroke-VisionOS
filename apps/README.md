# Apps

## Stroke Care

[`StrokeCare`](StrokeCare) is the active visionOS prototype: a clinician-paced,
three-act spatial explanation for a fictional stroke case. It includes a
case-file threshold, registered anatomy shortlist, patient/family and presenter
views, explicit clarification, consent-gated non-graphic layer reveal, spatial
audio, and deterministic Simulator proof routes.

The current branch is intentionally a work in progress. The next interaction
pass replaces the flat case board and bottom panel with side-parked spatial
files, progressive fact reveal, a private presenter rail, and a separate family
question surface.
